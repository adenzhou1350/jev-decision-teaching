## 推箱子：端到端闭环

训练集含 256 个单箱布局、11,151 个状态；dev/test 各 32 个布局、128 个起点；
双箱 OOD 12 个布局、48 个起点。按墙壁和目标布局的旋转/镜像等价类隔离。
最短路径来自离线精确 BFS，在线策略只读墙/目标/箱子/玩家四通道。

36 万参数的 CNN + 共享候选头，监督训练 60 epoch，按 dev 通关率选择第 55 epoch。
该轮优化和 dev 评估合计 15.98 秒（不含生成数据、最终 test/OOD 评测）；
其中一部分时间与另一个特征提取任务并行，不能作为独占硬件训练速度基准。

| 方法 | 单箱 test | 双箱 OOD |
| --- | ---: | ---: |
| 随机初始化 | 2/128 | 0/48 |
| 随机合法动作 | 28/128 | 4/48 |
| 贪心距离 | 14/128 | 2/48 |
| 训练后 | 122/128 | 25/48 |

单箱成功局平均 6.57 步；成功局都走出了最短路径。失败局保留为失败，没有求解器兜底。
双箱仅完成 52.1%，是明确的分布变化失败证据。
6×6 小棋盘和单箱任务相对简单，本结果不能替代标准大型 Sokoban 评测。

## 常驻服务实测

训练结束后启动服务（当前入口为 `python -m jev_teaching`），通过真正的 HTTP 请求重跑全部 176 个 test/OOD 起点的训练前和训练后策略，
并调用全部 72 个浏览器留出题的三个策略。HTTP 得到的完成数与离线报告完全一致。
自定义任务另外验证：服务不会沿用原题金标声称正确。

| 测量 | P50 | P95 | 样本与边界 |
| --- | ---: | ---: | --- |
| 推箱子单次 HTTP 决策 | 15.17 ms | 26.85 ms | 1,902 次 localhost 请求；CPU 策略，含网络栈与序列化 |
| 页面按钮单次 HTTP 决策 | 377.67 ms | 624.68 ms | 72 条 after 请求；GPU 底座，含分词、编码、HTTP |
| 推箱子进程内单次推理 | 0.335 ms | 0.539 ms | 100 次；含棋盘编码和合法动作判定，不含 HTTP |

Qwen 首次 HTTP 请求包含快照指纹核验和模型加载，共 22.26 秒，单独记录，不混入常驻分位数。
服务采用单请求、未优化的教学实现；这些时间不是并发吞吐或其他硬件的保证。
12 题的进程内浏览器抽样另存于 [browser-results.json](../artifacts/browser/browser-results.json)，主要服务口径以 72 题 HTTP 实测为准。
完整动作、响应结果和耗时数组见 [live-check.json](../artifacts/live-check.json)。

## 可以复核哪些部分

先按安装指南准备虚拟环境。命令均在仓库根目录执行；Linux/macOS 将 `.\.venv\Scripts\python.exe` 换成 `.venv/bin/python`。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m jev_teaching.audit_results --artifacts artifacts/sokoban --out runs/my-audit.json
.\.venv\Scripts\python.exe -m jev_teaching --model models/Qwen3.5-0.8B --device cuda
# 新终端中运行
.\.venv\Scripts\python.exe -m jev_teaching.verify_demo --out runs/my-http-check.json
```

单元测试覆盖规则、精确解、候选顺序、几何增强、标签不进 prompt、数据分组与实体交叉。
轨迹审计重新执行保存的每一步，并检查最终状态、最短距离、报告汇总与数据身份。
网页另做真实点击：训练前循环、训练后通关、按钮生效、自定义指令和错误反馈。

本版的产出定位是可玩的、可验证的教学项目。还没有训练多种随机种子、做大规模真实页面测试，
也没有证明新的模型结构或论文结论。已有 test 结果公开后，后续调参应保留它作为开发材料并新增最终测试集。
